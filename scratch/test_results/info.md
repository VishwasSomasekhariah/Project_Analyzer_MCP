| #     | Strategy (what you add to your pipeline)                                                                                                                                                                                                                                                                           | How others do it                                                                           | Pros for us                                                                                                       | Trade-offs / Effort                                                                                      |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **A** | **“External-flag overlay” on existing CPG**<br>Simply mark any node with no local body as `external`, keep graph otherwise unchanged.                                                                                                                                                                              | Fraunhofer CPG, Joern core (`IS_EXTERNAL=true`)                                            | Zero parsing of libraries; works today; lets you keep data-/control-flow edges intact if you create *stub* nodes. | Still cannot tell **stdlib vs 3ʳᵈ-party** without extra tags.                                            |
| **B** | **Semantic layer with function summaries**<br>Add a table saying “call X taints/cleans data, allocates memory…”.                                                                                                                                                                                                   | Joern **Semantic CPG**                                                                     | Preserves precise data-flow across library boundaries; lets security queries ignore library internals.            | Need to curate/write summaries; no automatic origin taxonomy.                                            |
| **C** | **Static name-resolution graph (Stack Graphs)**<br>Use Tree-sitter-based scope rules to wire every identifier to a def or create an external stub.                                                                                                                                                                 | GitHub’s *Stack Graphs* project                                                            | Language-agnostic, build-free, scales to millions of files; plugs straight into Tree-sitter.                      | Must author/maintain per-language resolution rules; still need origin tagging.                           |
| **D** | **Origin-tagging heuristics**<br>Post-process all external stubs: 1) compare module/header names against curated *std-lib lists*; 2) scan manifest files (`package.json`, `pom.xml`, `Cargo.toml`, …); 3) apply include-style hints (`<stdio.h>` vs `"boost/…"`) ; 4) optionally consult LSP “assembly/JAR” hints. | Many SAST tools (e.g., CodeQL model packs, commercial scanners) rely on similar heuristics | Gives the **stdlib / third-party** split we’re missing; language-agnostic because lists & parsers live in JSON.   | Lists drift over time; corner-cases need overrides.                                                      |
| **E** | **Import the *headers / stubs* of common std-libs**<br>Ship lightweight Tree-sitter-parseable header sets (e.g., C/C++ `<*.h>`, Java `java.*` skeletons) so std-lib entities get full AST nodes.                                                                                                                   | Fraunhofer CPG ships a minimal libc header pack; IDEs do similar.                          | Improves call-site linking accuracy; no copyright worry (headers are public).                                     | Still need third-party stubs; small maintenance burden per language revision.                            |
| **F** | **Harvest 3ʳᵈ-party source from package managers on demand**<br>For a repo that uses “requests”, fetch its sdist, parse with Tree-sitter, import into graph.                                                                                                                                                       | Deep-scan commercial SCA tools; some CodeQL pipelines pull Maven deps.                     | Maximum precision; enables whole-library flow analysis if needed.                                                 | Heavy network / storage cost; breaks “no build” principle; difficult for legacy langs (Fortran/Cobol).   |
| **G** | **Switch to compiler-driven indexers** (CodeQL, Kythe, LSIF)                                                                                                                                                                                                                                                       | CodeQL, Kythe, Sourcegraph                                                                 | Gives typed AST + full dependency map out-of-box; mature query ecosystems.                                        | Violates our *language-agnostic & build-free* constraint; high infra; each new language ≈ new extractor. |
| **H** | **Hybrid: Fraunhofer/Joern base + Stack-Graphs + Heuristic Tagger** (A + C + D)                                                                                                                                                                                                                                    | None single tool but composition of best ideas                                             | Lightweight, no compilers; precise cross-file linking; std/3p labels; reuses our current Tree-sitter assets.      | Needs engineering glue: run stack-graph pass, then tagging overlay, then store tags in CPG.              |
